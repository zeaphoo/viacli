## 命令分类

### 工具类
- `weather` - 天气查询（无需配置）
- `finance` - 金融数据（无需配置）

### 消息平台
- `qqbot` - QQ Bot API（需要配置 AppID/Secret）
- `weixin` - 微信 iLink API（需要配置 AppID/Secret）
