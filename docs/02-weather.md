# Weather 命令 - 天气查询

查询城市天气信息，无需 API Token。

## 数据源

- wttr.in

## 用法

```bash
viacli weather <城市名>
```

## 示例

```bash
# 查询北京天气
viacli weather 北京

# 查询上海天气
viacli weather Shanghai

# 查询纽约天气
viacli weather NewYork
```

## 输出说明

命令会显示以下信息：
- 当前温度
- 天气状况
- 湿度
- 风速
- 未来几天预报

## 特点

- ✅ 无需注册 API
- ✅ 支持中英文城市名
- ✅ 支持全球城市
